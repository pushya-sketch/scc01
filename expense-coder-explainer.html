Expense Coder · web app plan

Bank lines and bills in.
Coded expenses out.

A low-cost web app that reads a client's bank statements and scanned bills, picks the expense account for each payment, and hands back a sheet ready to import into Sage or QuickBooks. The bookkeeper only checks the rows it is unsure about.

You upload

  • once Trial balance (chart of accounts)
  • .csv Bank statements, one per bank account
  • .jpg .pdf Scanned expense bills

You download

  • .xlsx Coded expenses in columns A to E
  • .csv Sage 50 bank payment import
  • .csv Journal import for Sage Accounting or QuickBooks

For the bookkeeper

What a month looks like

Set up a client once

  1. Add the client in the app.
  2. Upload the trial balance.
  3. Confirm which accounts are expenses and which are banks.
  4. Check the keyword list for each expense account.

Every month, about 20 minutes

  1. Drop in the bank CSVs and the bill scans.
  2. Review the yellow and red rows; change codes from the dropdown.
  3. Download the Excel and the import file.
  4. Import into Sage or QuickBooks.
  5. Export the rules file as a backup.
Acceptance

How we know version 1 works

One real month for one real client must meet these targets.

Bank payments read from each CSV
100%
Bills matched to the right payment
≥ 95%
Bills read correctly (clear scans)
≥ 85%
Right code with no correction
70% → 85%
Wrong codes marked High confidence
< 2%

Also required: the import file loads into Sage or QuickBooks with no errors, the Excel total equals the bank payments total, and no client data shows in the browser's network log. The correct-code target rises from 70% in month 1 to 85% by month 3 as vendor rules build up.

Release plan

Phase 2

Test

One real month for one client on the preview link, checked against the targets.

Phase 3

Go live

Merge into main. Cloudflare publishes it as the production site.

Phase 4

Widen

Add clients one at a time and track the correction rate each month.

Before we build

Six answers needed

Roar AI and client dataDo client agreements allow bills to go to Roar AI? Its docs don't say how long requests are kept, so ask Roar in writing.
Roar AI accountWho owns the workspace and pays the bill? Is a newer Haiku than claude-haiku-4-5 on its model list?
Which Sage?Sage 50, Sage Accounting (cloud), or both. Each has its own import layout.
VATDo these clients reclaim VAT? If so, should the app split net and VAT on each bill?
Sign-inPut the site behind a staff sign-in, or open to anyone with the link?
Web addressA free pages.dev address, or the practice's own domain?
